# Ordenação
É o conceito de ordenar uma entrada, como vetores, a partir de uma padrão (crescente ou decrescente).

## estável e não estável
- um método estável preserva a ordem relativa dos elemenos que possuem o mesmo valor para chave de ordenção.
- um não estável não preserva essa ordem.

## In place (in situ)
Altera a entrada e não cria um novo elemento para armazenar os dados.

## Métodos de ordenação

### Bubble Sort
- Compara pares de elementos adjacentes; se o elemtno da esquerda é maior que o da direita, troca-os de posição.
- executa até n-1 dependendo da execução.

### Selection Sort
- Primeiro assume que o menor elemento está no primeiro índice do vetor não ordenado.
- Compara todos os valores do vetor não ordenado com o menor valor.
- Após ler todos os valores e comparar com o menor, faz a troca entre o índice atual e o menor.
- Repete o processso até finalizar.
